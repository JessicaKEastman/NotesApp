# NotesApp
This is my local notes app built from HTML, CSS, and javascript. 

## Version 0:
The app allows you to select a folder in which to store notes, create new folders and new .md files.
The notes are written in Markdown using MathJax for equations. The user writes in the text editing area and the results are rendered in the preview area.
Version is functional. Next version will add stylistic elements for the aesthetics of the app.
